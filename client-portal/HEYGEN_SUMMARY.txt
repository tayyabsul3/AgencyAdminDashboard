OPTION 2: Manual Deployment
┌───────────────────────────────────────────────────────────────────────────┐
│ Step 1: Deploy Backend                                                   │
│   firebase deploy --only functions:heygen                                │
│                                                                           │
│ Step 2: Configure Webhook (IMPORTANT!)                                   │
│   1. Go to https://app.heygen.com/settings/webhooks                      │
│   2. Add webhook endpoint                                                │
│   3. URL: https://us-central1-YOUR_PROJECT.cloudfunctions.net/heygen/    │
│           webhook                                                         │
│   4. Subscribe to: avatar_video.success, avatar_video.fail               │
│   5. Save and test                                                        │
│                                                                           │
│ Step 3: Test Endpoints                                                   │
│   # Get auth token from browser DevTools                                 │
│   # Application > IndexedDB > firebaseLocalStorage > accessToken         │
│                                                                           │
│   # Test avatars endpoint                                                │
│   curl -H "Authorization: Bearer YOUR_TOKEN" \                           │
│        https://YOUR_DOMAIN/heygen/avatars                                │
│                                                                           │
│   # Test voices endpoint                                                 │
│   curl -H "Authorization: Bearer YOUR_TOKEN" \                           │
│        https://YOUR_DOMAIN/heygen/voices                                 │
└───────────────────────────────────────────────────────────────────────────┘
